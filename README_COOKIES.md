# Instagram Cookie-Based Authentication

Instagram has been blocking server IPs from scraping. To bypass this, you can use cookie-based authentication.

## How It Works

The downloader will:
1. First try to extract the video without cookies (current behavior)
2. If that fails, try again with cookies if a cookies file is available
3. If neither works, return an error

Cookies are optional - the code works without them, but extraction success rate is higher with authentication.

## Setup Instructions

### Option 1: Using Browser Extension (Recommended)

1. **Install a cookie export extension**:
   - Chrome: "Get cookies.txt LOCALLY" by hotplasma
   - Firefox: "cookies.txt" by nicokant

2. **Log into Instagram** in your browser:
   - Go to https://www.instagram.com and log in with your account

3. **Export cookies**:
   - Click the extension icon
   - Export as "Netscape cookies.txt format"
   - Save the file as `instagram_cookies.txt`

4. **Place the file**:
   - Copy `instagram_cookies.txt` to the `media/` directory in your project
   - OR set the `INSTAGRAM_COOKIES_PATH` environment variable to the file path

### Option 2: Using Developer Tools

1. Open Instagram in Chrome/Firefox
2. Press F12 to open Developer Tools
3. Go to Application (Chrome) or Storage (Firefox) > Cookies > instagram.com
4. Export all cookies to a text file in Netscape format

### Environment Variable

Set `INSTAGRAM_COOKIES_PATH` to point to your cookies file:

```bash
# In your environment
export INSTAGRAM_COOKIES_PATH=/path/to/instagram_cookies.txt

# Or in Render/Railway/etc environment variables
INSTAGRAM_COOKIES_PATH=/path/to/instagram_cookies.txt
```

### Default Location

If no environment variable is set, the code looks for:
```
media/instagram_cookies.txt
```

## Cookie File Format

The cookies file should be in Netscape format (like cookies.txt):

```
# Netscape HTTP Cookie File
# This file was generated by cookies.txt extension
.instagram.com	TRUE	/	TRUE	1735689600	ds_user_id	12345678
.instagram.com	TRUE	/	TRUE	1735689600	sessionid	ABC123...
```

## Security Notes

- Keep your cookies file secure - don't commit it to version control
- Add `instagram_cookies.txt` to your `.gitignore`
- Instagram cookies expire after some time - re-export if extraction fails
- Use a separate account for extraction to avoid risking your main account

## Troubleshooting

**"No video formats found"**: Try re-exporting fresh cookies while logged into Instagram

**"Extraction failed"**: Cookies may have expired - export new ones

**Works without cookies but not with**: The cookies file format may be incorrect - ensure it's in Netscape format
